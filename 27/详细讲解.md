# LeetCode 27. 移除元素 - 详细思路讲解

## 一、问题理解

### 题目要求
1. **原地修改**数组 `nums`，移除所有等于 `val` 的元素
2. **返回**不等于 `val` 的元素数量 `k`
3. **确保**数组的前 `k` 个元素都是不等于 `val` 的元素
4. 数组的其余元素和数组大小不重要

### 关键点
- **不能使用额外数组**（空间复杂度 O(1)）
- **必须修改原数组**（评测机会检查 `nums[0:k]`）
- **顺序可以改变**（题目明确说明）

---

## 二、双指针方法思路

### 核心思想
使用**两个指针**：
- **快指针（right）**：遍历整个数组，寻找非 `val` 的元素
- **慢指针（left）**：指向下一个应该放置非 `val` 元素的位置

### 算法流程
1. 初始化 `left = 0`（慢指针）
2. 用 `right` 从 0 开始遍历数组
3. 当 `nums[right] != val` 时：
   - 将 `nums[right]` 赋值给 `nums[left]`
   - `left` 指针右移一位
4. 当 `nums[right] == val` 时：
   - 跳过，只移动 `right` 指针
5. 遍历结束后，`left` 就是答案

## 三、逐步演示

### 示例 1：nums = [3, 2, 2, 3], val = 3

#### 初始状态
```
索引:  0  1  2  3
nums: [3, 2, 2, 3]
      ↑
    left=0, right=0
```

#### 步骤 1：right=0, nums[0]=3 == val
```

nums: [3, 2, 2, 3]
      ↑  ↑
    left=0, right=0 (nums[0]==3，跳过)
    
操作：right++ → right=1
```

#### 步骤 2：right=1, nums[1]=2 != val
```
索引:  0  1  2  3
nums: [3, 2, 2, 3]
      ↑     ↑
    left=0, right=1 (nums[1]==2，保留)
    
操作：nums[0] = nums[1] = 2
     left++ → left=1
     right++ → right=2
     
结果：nums = [2, 2, 2, 3]
```

#### 步骤 3：right=2, nums[2]=2 != val
```
索引:  0  1  2  3
nums: [2, 2, 2, 3]
         ↑     ↑
      left=1, right=2 (nums[2]==2，保留)
      
操作：nums[1] = nums[2] = 2
     left++ → left=2
     right++ → right=3
     
结果：nums = [2, 2, 2, 3]
```

#### 步骤 4：right=3, nums[3]=3 == val
```
索引:  0  1  2  3
nums: [2, 2, 2, 3]
            ↑     ↑
         left=2, right=3 (nums[3]==3，跳过)
         
操作：right++ → right=4（超出范围，结束）
```

#### 最终结果
```
返回 k = left = 2
nums 前 2 个元素：[2, 2]  ✓
完整数组：[2, 2, 2, 3]（后面的元素不重要）
```

```
           ↑  ↑
         left right

步骤3： [2, 2, 2, 3]  (2 != val，复制并移动)
              ↑  ↑
            left right

              ↑     ↑
            left  right (结束)

结果：前 2 个元素 [2, 2] 都是非 val 元素
```

## 五、为什么这个方法有效？

### 1. 为什么不会覆盖未处理的元素？
- **关键观察**：`left` 总是 ≤ `right`
- 当 `nums[right] != val` 时，我们将 `nums[right]` 复制到 `nums[left]`
- 因为 `left ≤ right`，所以 `nums[left]` 要么是：
  - 已经被处理过的位置（`left < right`）
  - 或者是当前位置（`left == right`，自己复制给自己，没问题）

### 2. 为什么能保证前 k 个元素都是非 val？
- 只有当 `nums[right] != val` 时，我们才会将其放到 `left` 位置
- 所以 `nums[0]` 到 `nums[left-1]` 都是非 `val` 元素
- 最终 `left` 就是非 `val` 元素的数量

### 3. 为什么顺序可以改变？
- 题目明确说明："元素的顺序可能发生改变"
- 我们只是将非 `val` 元素移到前面，不保证保持原顺序
- 评测机会对前 `k` 个元素排序后再比较

## 六、代码实现

```python
class Solution(object):
    def removeElement(self, nums, val):
        """
        :type nums: List[int]
        :type val: int
        :rtype: int
        """
        left = 0  # 慢指针：指向下一个非 val 元素应该放置的位置
        
        # 快指针 right 遍历整个数组
        for right in range(len(nums)):
            if nums[right] != val:
                # 将非 val 元素移到前面
                nums[left] = nums[right]
                left += 1
        
        return left  # left 就是非 val 元素的数量
```

---

## 七、复杂度分析

### 时间复杂度：O(n)
- 只需要遍历数组一次
- `right` 指针从 0 到 n-1，共 n 次操作

### 空间复杂度：O(1)
- 只使用了常数个额外变量（`left`）
- 没有使用额外的数组

## 八、与其他方法的对比

### 方法 1：使用额外数组（不符合要求）
```python
# 不符合"原地修改"的要求
new_nums = []
for num in nums:
    if num != val:
        new_nums.append(num)
return len(new_nums)
```
- ❌ 空间复杂度 O(n)
- ❌ 没有修改原数组

### 方法 2：使用 remove() 方法（效率低）
```python
# 效率低，每次 remove 都是 O(n)
while val in nums:
    nums.remove(val)
return len(nums)
```
- ❌ 时间复杂度 O(n²)
- ❌ 每次 remove 都要移动后续元素

### 方法 3：双指针（推荐）✓
- ✅ 时间复杂度 O(n)
- ✅ 空间复杂度 O(1)
- ✅ 原地修改数组

## 九、常见错误

### 错误 1：只计数，不修改数组
```python
count = 0
for num in nums:
    if num != val:
        count += 1
return count  # ❌ 没有修改数组
```

### 错误 2：从后往前遍历，逻辑复杂
```python
# ❌ 容易出错，容易越界
p = len(nums) - 1
while p >= 0:
    if nums[p] == val:
        # 移动元素逻辑复杂，容易出错
```

### 错误 3：使用 pop() 方法
```python
# ❌ 改变数组长度，索引会混乱
i = 0
while i < len(nums):
    if nums[i] == val:
        nums.pop(i)  # 删除后，后续元素索引都变了
    else:
        i += 1
```

## 十、总结

### 核心要点
1. **双指针技巧**：快指针遍历，慢指针记录位置
2. **原地修改**：将非 `val` 元素移到数组前面
3. **一次遍历**：时间复杂度 O(n)
4. **常数空间**：只使用额外变量，空间复杂度 O(1)

### 适用场景
- 需要原地修改数组
- 需要移除特定元素
- 不要求保持原顺序
- 要求 O(1) 空间复杂度
