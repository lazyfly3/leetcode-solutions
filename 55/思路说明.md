# 跳跃游戏 - 算法思路详解

## 问题分析

给定一个非负整数数组 nums，每个元素表示在该位置可以跳跃的最大长度。
判断是否能够从第一个位置到达最后一个位置。

### 核心思想

我们不需要知道具体怎么跳，只需要知道能否到达。关键在于维护"能到达的最远位置"。

---

## 方法1：贪心算法（推荐）

### 核心思路

1. 维护一个变量 `max_reach`，表示当前能到达的最远位置
2. 遍历数组，对于每个位置 i：
   - 如果 `i > max_reach`，说明无法到达位置 i，返回 False
   - 否则，更新 `max_reach = max(max_reach, i + nums[i])`
   - 如果 `max_reach >= 最后一个位置`，返回 True

### 为什么这样做是正确的？

**关键洞察**：如果位置 i 能到达，那么从位置 i 能到达的所有位置（i 到 i+nums[i]）也都能到达。

**证明**：
1. 假设我们能够到达位置 i，那么 `max_reach >= i`
2. 从位置 i 最多能跳到 `i + nums[i]`
3. 所以能到达的最远位置至少是 `max(max_reach, i + nums[i])`
4. 如果某个位置 `j > max_reach`，说明无法到达位置 j

### 贪心策略的正确性

- 我们总是维护"能到达的最远位置"，这是局部最优选择
- 如果某个位置无法到达，那么它后面的位置也无法到达（因为无法跳过它）
- 如果最远位置 >= 最后一个位置，那么一定能到达最后一个位置

### 复杂度分析

- **时间复杂度**：O(n) - 只需遍历一次数组
- **空间复杂度**：O(1) - 只用了常数个变量

---

## 方法2：动态规划（从后往前）

### 核心思路

1. 定义 `dp[i]` 表示从位置 i 能否到达最后一个位置
2. 初始化：`dp[n-1] = True`（最后一个位置肯定能到达）
3. 从后往前遍历，对于位置 i：
   - 检查从位置 i 能跳到的所有位置 j（i+1 到 i+nums[i]）
   - 如果存在某个 j 使得 `dp[j] = True`，则 `dp[i] = True`

### 为什么从后往前？

因为我们需要知道后面的位置能否到达终点，才能判断前面的位置能否到达终点。
这是一个典型的"依赖后续状态"的动态规划问题。

### 状态转移方程

```
dp[i] = True  如果存在 j ∈ [i+1, i+nums[i]] 使得 dp[j] = True
dp[i] = False 否则
```

### 复杂度分析

- **时间复杂度**：O(n²) - 对于每个位置，最多检查 nums[i] 个后续位置
- **空间复杂度**：O(n) - 需要存储 dp 数组

---

## 方法3：优化的贪心算法

### 核心思路

与方法1基本相同，但写法更简洁：
- 遍历完整个数组后，检查 `max_reach >= n-1`

### 为什么可以这样优化？

- 如果遍历过程中没有提前返回 False，说明所有位置都能到达
- 最后只需要检查最远位置是否 >= 最后一个位置即可
- 这样可以减少循环中的判断，代码更简洁

### 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

---

## 方法对比与选择

### 推荐使用方法1（贪心算法）

1. 时间复杂度最优：O(n)
2. 空间复杂度最优：O(1)
3. 逻辑清晰，易于理解
4. 可以提前返回，效率高

### 动态规划方法虽然也能解决问题，但：

- 时间复杂度更高：O(n²)
- 空间复杂度更高：O(n)
- 适合需要记录具体路径的场景

---

## 关键理解点

### 1. 为什么不需要记录具体路径？

- 题目只问能否到达，不问怎么到达
- 我们只需要知道"能到达的最远位置"即可

### 2. 为什么贪心策略是正确的？

- 如果位置 i 能到达，那么从 i 能到达的所有位置也都能到达
- 维护最远位置就是维护所有能到达位置的集合的上界

### 3. 为什么 i > max_reach 时返回 False？

- 如果当前位置都无法到达，那么后面的位置更无法到达
- 因为要到达后面的位置，必须先到达当前位置

### 4. 边界情况处理

- 数组长度为 1：已经在最后一个位置，返回 True
- 第一个位置为 0：如果数组长度 > 1，无法继续，返回 False

---

## 执行示例

### 示例1：`[2, 3, 1, 1, 4]`

```
位置 0: nums[0]=2, max_reach = max(0, 0+2) = 2
位置 1: nums[1]=3, max_reach = max(2, 1+3) = 4
  -> max_reach(4) >= 最后一个位置(4)，可以到达！返回 True ✓
```

### 示例2：`[3, 2, 1, 0, 4]`

```
位置 0: nums[0]=3, max_reach = 3
位置 1: nums[1]=2, max_reach = 3
位置 2: nums[2]=1, max_reach = 3
位置 3: nums[3]=0, max_reach = 3
位置 4: 4 > max_reach(3)，无法到达，返回 False ✗
```
